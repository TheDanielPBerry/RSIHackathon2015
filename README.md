# RSI Hackathon 2015 First Place Winner
For the 2015 Hackathon hosted by RSI in Augusta, Georgia, we were tasked with a bug finding bounty.  
After being unable to get the project to build, we decided to build the project from scratch.  
Due to our efforts we were awarded first prize in the Hackathon.  
This repo contains the code for the project complete with all of the bugs and vulnerabilities to be expected in a project like this.  

## `hosted` Branch
The branch named `hosted` contains code that has had the security vulnerabilities removed.  
It is hosted at <https://hack2015.danielberry.tech>
